## 📌 Atividade 1: Mux 4:1 (32 bits)

### 🔍 Descrição do Projeto
Implementação de um multiplexador (Mux) 4:1 com barramento de dados de 32 bits. 
O circuito foi projetado estruturalmente em **nível de portas lógicas**, utilizando o conceito de **array de portas lógicas** para execução.


### ⚙️ Tecnologias e Ferramentas
* **Linguagem/Software:**  SystemVerilog / Modelsim
